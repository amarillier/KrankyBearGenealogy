KrankyBear Genealogy Sample Data
=================================

DEMO DATABASE
-------------
The demo database is now built into the application!

To load the demo:
  1. Launch KrankyBear Genealogy
  2. Go to: Help → Load Demo Database
  3. Click "Generate Demo"

The demo database contains synthetic genealogical data designed to showcase
all features of KrankyBear Genealogy:

• 40 people across 5 generations (Harrison family tree)
• Multiple marriages and divorces
• Living people with contact information
• Geographic diversity (births/deaths across USA)
• Intentional data quality issues to demonstrate reports:
  - Incomplete records (for Data Quality Report)
  - Impossible relationships (for Conflicts Report)
  - Duplicate names (for Duplicate Detection)
  - Living status issues (for Living Status Report)

The demo generates instantly - no separate download needed.

📷 Demo with Media:
   For a complete demo experience including photos and documents, download
   the full demo database from the GitHub repository (14Mb):
   • Includes media for Michael John Harrison (focus person)
   • Photos of Jennifer Martinez (his second wife)  
   • Birth certificates and photos for children Esther Ruth and Noah Daniel
   • Demonstrates media library, attachment, and viewing features
   • All data is fictional, no real people, images, or other media



SAMPLE GEDCOM FILES
-------------------
These are real genealogical datasets from various sources, provided for
testing import functionality:

• bronte.ged - The Brontë family (famous authors)
• shakespeare.ged - Shakespeare family tree
• pres2020.ged - US Presidents through 2020
• royal92.ged - British Royal Family (1992)
• Jesus.ged - Biblical genealogy

These files are for developer/tester use and are not exposed in the
application UI. They can be imported via File → Import GEDCOM.


ATTRIBUTION
-----------
Sample GEDCOM files are from public genealogy sources and wikis.
Demo database uses synthetic data generated specifically for this application.

All data is provided for educational and testing purposes only.
