KrankyBear Genealogy - Release Notes

1.1.0 - January 20, 2026
━━━━━━━━━━━━━━━━━━━━━━━━
Major update with advanced reporting, data validation, and workflow improvements!

⌨️  Keyboard Shortcuts:
  • 20+ keyboard shortcuts for common actions (Cmd/Ctrl + key)
  • Fully customizable shortcut preferences
  • Conflict detection prevents duplicate key assignments
  • Access: Settings → Keyboard Shortcuts (Cmd/Ctrl+K)

🔍 Data Quality & Validation:
  • Conflicts Report: Detects impossible dates and relationships
  • Duplicate Detection: Intelligent matching with merge capability
  • Review/Validation System: Mark conflicts and duplicates as reviewed
  • Reviewed Items Report: Manage and unmark reviewed items
  • Filter controls to show/hide reviewed data

📊 Enhanced Reports:
  • Ancestor Report: Ahnentafel numbering with pedigree collapse detection
  • Descendant Report: Generation counts with interactive navigation
  • Timeline View: Chronological display of all life events
  • Geographic Distribution: Birth/death locations with filtering and sorting
  • Statistics Dashboard: Oldest living/deceased, average lifespan, and more

✅ Bulk Operations:
  • Mass "Mark as Living": Identify and bulk-update living status
  • Smart filtering by name with selection preservation
  • Sort by name or age for easy review
  • Select All/Deselect All for efficient workflow

🗺️  Geographic Features:
  • Location-based reports for births and deaths
  • Filter by location name
  • Sort by frequency or alphabetically
  • Interactive "Show People" for each location
  • Toggle birth/death location visibility



1.0.0 - January 18, 2026 - First Public Release
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
This is the first official public release of KrankyBear Genealogy!

✨ Core Features:
  • Three-view interface (Family, Pedigree, Individual)
  • GEDCOM, GenoPro, and Gramps import/export
  • Media management (photos, documents, videos)
  • Multiple marriage support with relationship tracking
  • Relationship calculator
  • Data quality and living status reports
  • Cross-platform (Windows, macOS, Linux)
  • Choose from portable stanadlone binaries or full installer options

📸 Media Management:
  • Store photos and documents in database or link externally
  • Many-to-many linking (one photo → multiple people)
  • Thumbnail generation
  • Support for images, PDFs, videos, Microsoft Office documents
  • Centralized Media Library

💾 Data Management:
  • SQLite database with hot-switching capability
  • Backup/restore with timestamped ZIP files
  • Branch export (person + descendants)
  • Smart relationship linking

🎨 User Experience:
  • Focus user preference
  • Theme support (Light/Dark/System)
  • Auto update checker
  • System tray integration
  • Universal search/filter

📋 Contact & Notes:
  • Contact information fields
  • Notes and annotations
  • Searchable and exportable

For complete feature list, see README.md
